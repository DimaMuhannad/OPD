# Комплект занятия: бланк + доска + рассылка

Порядок шагов и одобрения — в `/zanyatie`. Этот навык — **как** делать
части комплекта и какие ловушки уже встречались (занятия 8–9, 30.10–11.11).

## 1. Один комплект — две формы

- **Бланк А4** (docx, ч/б, альбомный, две стороны) и **доска Excalidraw** —
  одни и те же зоны: одинаковые номера, названия, порядок, подписи.
  Генераторы — рядом: `tools/docx-konspekt/build_Zanyatie_NN_*_A4_Blank.js`
  и `tools/excalidraw/zNN_board.js`; в шапке каждого — ссылка на другой.
- **Конспект один на оба режима.** Зона = раздел: зачем → шаги → пример
  горшка → «**На бланке.**» → «**На доске.**». Два конспекта не делать —
  логика расходится.
- **Конспект самодостаточен:** по нему делает пропустивший. Разделы
  «Как пользоваться», «Где мы», зоны, «Все зоны вместе / все связи»,
  «Частые вопросы», «Если вас не было / если работаете не всей командой»,
  «Что сдать» с критериями, «Вопросы для самопроверки».
- **Пример горшка сквозной между занятиями:** числа одного занятия — вход
  следующего (кошелёк 34/40 → план/факт +1 неделя → буфер израсходован).
  Перед новым занятием перечитать примеры прошлых.
- **Колода** — шпаргалка к конспекту: по слайду на зону (картинка зоны
  слева, «что делаем» и «зачем» справа). Если колод две (бланк / доска) —
  один генератор (`tools/marp/z08_decks.py`), различаются только картинки
  и слайд «как работать».
- На доске: рамки и подписи `locked`, стикеры свободные; серые «Пример:»
  (горшок) — «сотрите и впишите своё»; ключ к цвету (красный = критический
  путь) — строкой в зоне.

## 2. Если пара не состоялась

- Комплект заменяет пару: конспект + бланк + доска (+ таблица) + короткая
  колода; посты «без пары»: объявление (почему самостоятельно + **начинать
  работы из плана сейчас**: отложенный пакет сдвигает всё), материалы, ДЗ.
- Сдача вехи без пары — **фото в тему своей команды** в Telegram-группе
  (решение 11.11).
- Не обещать в постах того, чего нет в плане следующего занятия.

## 3. Доска Excalidraw и комнаты

- Сцена: `node tools/excalidraw/zNN_board.js <out> "<команда>"`.
  В генераторе **`setPrefix("zN_")`** — id элементов разных занятий не
  должны совпадать.
- Комната: `NODE_PATH=/opt/node-tools/node_modules node tools/excalidraw/room.js <сцена> <pngDir> --room`
  → строка `ROOM <url>`. Комната живёт на сервере Excalidraw, без регистрации.
  `--zones` — снимки по зонам для проверки глазами и для колоды
  (`zanyatiya/img/zNN_zoneK.png`).
- **Комната на каждую команду** с названием в шапке + одна запасная.
  Список — `zanyatiya/Zanyatie_NN_Doska_komnaty.md` (группа | команда | ссылка).
- **Проверка после создания:** `node tools/excalidraw/live.js read <url> <json>`
  в чистом браузере — число элементов как в сцене, название команды есть.
- **Правка живой комнаты** (студенты уже работают): `live.js read` →
  сравнить заменяемые зоны со свежей пустой сценой (тронуты? чужие стикеры
  внутри?) → только если не тронуты: `live.js zones <url> <сцена> 4,6`
  (ждёт 45 с) → `live.js read` и сверить, что вне зон ничего не пропало.
  Снова создавать комнату нельзя — ссылка у студентов.
- Стикер: ширину/высоту передавать в `sticker(x,y,label,{width,height})` —
  текст берёт ширину стикера (до 11.11 текст широких стикеров обрезался).

## 4. Google-таблица-шаблон

- Создаётся на Диске преподавателя (Google Drive / Sheets), студентам —
  ссылка `…/copy` («Создать копию»), оригинал не заполнять.
- **Локаль ru_RU: аргументы формул через «;»**, имена функций английские.
  Через «,» формула даёт `#ERROR!`.
- Маска полей в `repeatCell`: через запятую
  (`userEnteredFormat.textFormat,userEnteredFormat.wrapStrategy`), скобки не
  принимаются.
- Формулы проверять пробными строками и удалять их.
- Строка-пример — серым курсивом; выпадающие списки для статусов; пример не
  должен попадать в итоговые формулы.
- Доступ «по ссылке — читатель» — это расшаривание: делать только после
  явного разрешения преподавателя.

## 5. Telegram

- **Токен** — только `TG_BOT_TOKEN` в облачном окружении «ОПД» (claude.ai →
  строка окружения под названием сессии → «Изменить»). Сессия читает
  переменную **при запуске**: после замены нужна новая сессия. Сетевой
  секрет не подходит — Telegram ждёт токен в адресе, а не в заголовке.
  Если токен оказался в чате — попросить перевыпустить в @BotFather.
- Проверка связи: `getMe` (имя бота), `getChat` и `getChatMember` для обеих
  групп (бот — administrator). 401 = токен отозван/заменён, сеть ни при чём.
- **Темы команд** бот не может перечислить: попросить преподавателя
  написать по сообщению в каждую тему, сразу снять `getUpdates` (хранятся
  24 ч), записать в `groups.json` → `<группа>.teams` {название: thread_id}.
  Сейчас: м531 — 6 команд; м631к — 3 команды (собраны 12.11).
- Комплект постов: `tools/telegram/posts/ГГГГ-ММ-ДД_тема[-группа]/` —
  `1_obyavleniya.txt`, `2_materialy.txt` + `.files`, `3_domashnee_zadanie.txt`;
  отдельные комплекты на группу, если тексты расходятся (ссылки на доски).
- Публикация: `lint.py NN` → пробный прогон
  `telegram_publish.py publish <папка> --group m531|m631k|all` → показать
  **весь** текст → «да» опросником → `--send` → ссылки в `STATE.md`.
- Сообщения в темы команд (ссылка на доску) — отдельным вызовом
  `sendMessage` с `message_thread_id`; каждое записать в `sent_log.jsonl`.
- Англицизм в посте («чекпоинт») — с аналогом в скобках при первом
  упоминании в каждом посте (lint ловит).

## 6. Уроки (что уже шло не так)

| Что случилось | Как не повторить |
| --- | --- |
| Замена зон в живой комнате затёрла рамку соседней зоны (совпали id `r150`) | префикс id в генераторе; `live.js zones` проверяет совпадения и отказывает |
| Восстановленный элемент лёг поверх содержимого зоны | порядок элементов = порядок отрисовки; рамку вставлять перед содержимым, `index: null` |
| Правка в комнате не сохранилась | ждать ≥ 45 с перед закрытием браузера; всегда перечитывать в чистом браузере |
| Текст в широком стикере обрезан | `sticker` передаёт width/height в текст (исправлено 11.11) |
| `#ERROR!` в Google-таблице | ru_RU → «;» |
| Бот 401 после перевыпуска токена | новый токен → переменная окружения → новая сессия |
| `getUpdates` пуст | сообщения старше 24 ч или написаны до того, как бот стал админом — написать снова |
| Два конспекта под два режима | один конспект с пометками «На бланке / На доске» |
| Опечатка «комнаты» = темы Telegram или доски Excalidraw | переспросить опросником, если слово двусмысленно |

- [ ] пример горшка согласован с прошлыми занятиями;
- [ ] бланк — две страницы А4, обе стороны посмотрены глазами;
- [ ] каждая комната открыта в чистом браузере;
- [ ] таблица: формулы проверены пробными строками;
- [ ] `lint.py NN` — 0 ошибок и 0 «внимание» в постах;
- [ ] `STATE.md`: ссылки, что опубликовано, что нет.
