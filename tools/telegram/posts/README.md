# Посты для Telegram-группы

Группа разбита на темы (Telegram Topics / форум-режим): **Объявления**,
**Материалы**, **Домашнее задание**, **Литература**. Каждая подпапка ниже —
один комплект постов к одному занятию, файлы пронумерованы в порядке
публикации: сначала содержательные темы, «Объявления» — последними, чтобы
в них можно было вставить уже готовые ссылки на отправленные сообщения.

Файлы с приложениями к каждому комплекту (шаблоны, презентации, конспекты)
лежат в `zanyatiya/` — какие именно прикладывать к какому сообщению,
написано внутри текста самого поста «Материалы».

## Порядок публикации

1. Отправить «Материалы», «Домашнее задание» и (если есть) «Литературу».
2. Скопировать ссылку на каждое отправленное сообщение (см. ниже, как).
3. Отправить «Объявления», вставив эти ссылки на месте плейсхолдера
   `[после публикации вставить сюда ссылки на сообщения в … разделах]`.

## Перекрёстные ссылки между темами группы

Telegram-темы (Topics) — форумный режим супергруппы: у каждой темы свой
поток сообщений и свой номер (topic ID).

1. **Скопировать ссылку на сообщение.** В приложении: долгое нажатие на
   сообщение → «Копировать ссылку» (на десктопе — правый клик → «Copy
   Message Link»). Вид: `https://t.me/c/1234567890/45/128` (закрытая
   группа) или `https://t.me/имя_группы/45/128` (если у группы есть
   публичный юзернейм) — `45` — номер темы, `128` — номер сообщения внутри
   неё.
2. **Вставить ссылку текстом** в сообщение в другой теме — Telegram сам
   делает её кликабельной; по нажатию человека переносит прямо к нужному
   сообщению в нужной теме, с подсветкой.
3. **Альтернатива — Forward.** Чтобы не просто сослаться, а показать
   содержимое целиком (например, повторить прикреплённый файл),
   пересылайте сообщение через обычный Forward — исходный автор и тема
   сохранятся как подпись «Переслано из…».
4. Ссылка работает только при наличии доступа к группе — для закрытой
   группы это участники, для публичной открывается и извне.
