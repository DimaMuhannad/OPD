# ОПД / ОПДВП — методическая разработка курсов (ГУАП, Кафедра №3)

Рабочий репозиторий для Claude Code. Контекст курсов, критаудит и рабочие
материалы — см. `CLAUDE.md` (читается Claude Code автоматически при каждой сессии).

## Структура

- `opdvp/` — готовые материалы 1 курса
- `opd/` — готовые материалы 2 курса
- `tools/telegram/` — скрипт публикации в Telegram (Bot API)
- `source-pdfs/` — исходники: РПД обеих дисциплин, учебное пособие, расписание,
  презентации

## Формат файлов в `source-pdfs/`

Файлы лежат не в исходном формате, а в виде извлечённого содержимого — учитывать
при чтении:

| Файл | Что внутри на самом деле |
| --- | --- |
| `03_03_0102_О_ОПД_2025_0_3_1.pdf` | ZIP: 36 страниц, постранично `N.jpeg` + `N.txt` |
| `03_03_0102_О_ОПДВП_2026_0_3_1.pdf` | ZIP: 45 страниц, постранично `N.jpeg` + `N.txt` |
| `Уч_пособие_ОПД.pdf` | ZIP: 85 страниц, постранично `N.jpeg` + `N.txt` |
| `Расписание_занятий___ГУАП.pdf` | ZIP: 2 страницы, `N.jpeg` + `N.txt` |
| `Osnovy-proektnoj-deyatelnosti.pptx` | Текстовая выжимка слайдов (Markdown, `## Slide N`) |
| `Osnovy-proektnoj-deyatelnosti-v-professii.pptx` | То же |

Расширения `.pdf` / `.pptx` сохранены для совпадения с именами исходников, но
открывать эти файлы просмотрщиком PDF/PowerPoint нельзя — только через
`python zipfile` (архивы) или как текст (выжимки слайдов).

Текстовый слой есть не на всех страницах: титул и оборот обычно дают пустой
`.txt`, таблицы распознаются частично — сверяться с `.jpeg` той же нумерации.

## Секреты

`tools/telegram/telegram_publish.py` требует переменные окружения
`TG_BOT_TOKEN` и `TG_CHAT_ID` — **не коммитить их в репозиторий**, задавать
только как секреты сессии/окружения.
