# Архив

Сюда переносятся материалы, которые **заменены** новыми и больше не должны
попадаться под руку при подготовке к занятию. Файл уходит в архив, только
когда выполнены оба условия:

1. у него есть готовая замена, лежащая в рабочих папках;
2. в `CLAUDE.md` или `PLAN.md` записано, чем именно он заменён.

Материал не переносится в архив за то, что описывает РПД, расходящуюся
с нашей рабочей моделью: РПД — утверждённый документ, и её разбор остаётся
актуальным ровно до тех пор, пока действует сама РПД. Расхождения рабочей
модели с текстом РПД перечислены в `PLAN.md`, разделе «Чем программа
расходится с текстом РПД».

Удалять из архива ничего не нужно: история правок хранится в git, а архив
нужен для того, чтобы глазами не спотыкаться о заменённое.

## Что лежит здесь

Пока пусто — на 11.09.2026 ни один материал не заменён полностью.
