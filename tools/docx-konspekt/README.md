# Печатный docx-двойник конспекта

Конспект/методичка практики живёт как `.md` в `zanyatiya/` — это источник,
правки вносятся туда. Скрипты в этой папке собирают из него печатную
чёрно-белую версию в `.docx` через npm-пакет `docx` (`npm install docx@9`
в любой рабочей папке с `node_modules`, например в scratchpad сессии).

Правило: содержание (текст, таблицы) копируется из актуального `.md`
вручную в скрипт при сборке или обновлении — скрипт не парсит Markdown
автоматически. При правке конспекта соответствующий блок в скрипте
поправить тем же изменением, не давать им разойтись.

Цвета — без раскраски: чёрный текст (`#1A1A1A`), бледно-серая заливка
(`#E8E8E8`) для шапок таблиц и колл-аутов «Ориентир»/«Определение»,
серые линии (`#999999`) вместо акцентного синего под заголовками. Та же
логика, что в чёрно-белом `Zanyatie_04_Pasport_Blank.docx`.

Проверка перед сдачей: `zipfile` + `xml.dom.minidom.parseString` на
`word/document.xml` (LibreOffice файлы от `docx`-пакета не открывает —
известное ограничение, см. `CLAUDE.md`), и сверка количества таблиц
и текста построчно с исходным `.md`.
