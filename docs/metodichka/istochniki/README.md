# Выписки из первоисточников

Правило (17.10.2026): определения, названия и утверждения из источников берутся в текст книги и РПД
**только по выписке отсюда**, не по памяти и не по вторичным обзорам. Нет выписки — пометка «[уточнить: …]».

Одна выписка — один файл `<ключ>.md`, где ключ совпадает с ключом в `kniga/istochniki.bib` (если он
там есть). В файле:

1. **Выходные данные** — по ГОСТ Р 7.0.100–2018; для сайта — URL и дата обращения.
2. **Статус источника** — первоисточник (текст стандарта), официальный материал издателя, вторичный обзор.
3. **Цитаты** — дословно, на языке оригинала, со страницей или номером слайда.
4. **Наш перевод** — рядом с цитатой; термин — по таблице `PRAVILA_KONTENTA.md`.
5. **Где используется** — параграфы книги, разделы РПД.

Полные тексты платных изданий (PMBOK) в репозиторий не кладутся — только короткие цитаты для ссылок.
