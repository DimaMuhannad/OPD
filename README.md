# ОПД / ОПДВП — методическая разработка курсов (ГУАП, Кафедра №3)

Рабочий репозиторий для Claude Code. Контекст курсов, критаудит и рабочие
материалы — см. `CLAUDE.md` (читается Claude Code автоматически при каждой сессии).

## Структура

- `opdvp/` — готовые материалы 1 курса
- `opd/` — готовые материалы 2 курса
- `tools/telegram/` — скрипт публикации в Telegram (Bot API)
- `source-pdfs/` — исходные РПД и учебник (добавить вручную, см. ниже)

## Что нужно добавить вручную

Исходные PDF (РПД обеих дисциплин, учебник Редько, презентации, расписание)
не входят в этот архив — их нужно скопировать из Project Files claude.ai
в `source-pdfs/` перед первым запуском Claude Code:

- `03_03_0102_О_ОПДВП_2026_0_3_1.pdf`
- `03_03_0102_О_ОПД_2025_0_3_1.pdf`
- `Уч_пособие_ОПД.pdf`
- `Osnovy-proektnoj-deyatelnosti.pptx`
- `Osnovy-proektnoj-deyatelnosti-v-professii.pptx`
- `Расписание_занятий___ГУАП.pdf`

## Секреты

`tools/telegram/telegram_publish.py` требует переменные окружения
`TG_BOT_TOKEN` и `TG_CHAT_ID` — **не коммитить их в репозиторий**, задавать
только как секреты сессии/окружения.
