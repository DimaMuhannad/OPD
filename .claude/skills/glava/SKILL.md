# Глава книги: порядок шагов

Аргумент — номер параграфа по `docs/metodichka/STRUKTURA.md` (например, `/glava 3.3`).
Правила **содержания** — `docs/metodichka/PRAVILA_KONTENTA.md` и `CLAUDE.md` (тон, словарь вводной
лекции, умный горшок, ссылки по смыслу, источники). Этот навык задаёт **порядок** и **проверки**.

## Границы направления

- Ветка `claude/metodichka-rpd`; PR не создавать. Свежие конспекты занятий — merge
  `origin/claude/archive-to-repository-heyt7z` (не rebase).
- **Не трогать** `zanyatiya/`, `tools/telegram/`, `testy/`, общий `STATE.md`, `CLAUDE.md` — их ведёт
  сессия занятий. Всё своё — в `docs/metodichka/`.
- Вопросы преподавателю — опросником (AskUserQuestion). В Telegram ничего не публиковать.

## Главные принципы

1. **Один шаг — одно одобрение.** После шага коротко показать результат и спросить опросником,
   идти ли дальше.
2. **Источники не выдумывать.** Нет выходных данных — пометка «[уточнить: …]». Определение без
   известного источника — без атрибуции.
3. **Термины PMBOK 8** — русский перевод из `PRAVILA_KONTENTA.md` и английский оригинал в скобках при
   первом упоминании в параграфе. Порядок действий шага — по процессу PMBOK 6 из `STRUKTURA.md`.
4. **Каждое замечание преподавателя — в правило:** в `PRAVILA_KONTENTA.md`, а если проверяемо —
   в `kniga/proverka.py`.

## Технические ловушки (найдены на пилоте 3.2)

- Graphviz/pango: шрифт только как `«Times New Roman,»` (функция `pango()`), иначе молча Inter.
- Quarto 1.8: двойная точка в подписях, два `w:pPr`/`w:jc` в docx — чинит `posle_docx.py`.
- Typst внутри Quarto не берёт `number-offset`: номер главы и параграфа — строками
  `#counter(heading).update(…)` / `.step(level: 2)` в начале файла главы.
- Знака ₽ нет в Times New Roman из core fonts — писать «руб.».
- Разворот: `::: razvorot-levaya` / `::: razvorot-pravaya`; правая страница должна вместить рисунок и
  таблицу — проверять глазами.
