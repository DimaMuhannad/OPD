# pisatel — лёгкая GSD-подобная система для книг и документов

Плагин Claude Code. Состояние проекта лежит в файлах репозитория. Человек одобряет каждый шаг,
правила проекта живут в самом проекте (`CLAUDE.md`, файл правил, навыки проекта). Плагин даёт общий
каркас, который подходит любой книге или пачке документов.

| Команда | Что делает | Готово |
| --- | --- | --- |
| `/progress` | прогресс по `progress.toml`: полосы по разделам, вехи со сроками, что ждёт человека, расхождения с репозиторием, следующий шаг (аналог `/gsd:progress`) | да |
| `/brief N` | задание на главу или документ до написания: цель, место, опоры, содержание по блокам, источники, пример, рисунки, объём, **критерии готовности**, вопросы к автору (шаблон `templates/brief.md`) | да |
| `/review N` | автопроверки проекта + агент `svezhiy-chitatel` (только чтение) сверяет текст с правилами и критериями задания; правятся только одобренные замечания | да |
| `/doc` | мелкий документ: задание → черновик → проверка → docx | план |
| `/istochniki` | сверка выходных данных источников, описание по ГОСТ Р 7.0.100–2018 | план |

Навыки конкретного проекта (например, `/glava`, `/rpd` в репозитории ОПД) лежат в его `.claude/skills/`
и обновляют `progress.toml` после каждого шага.

## Настройка проекта

В `progress.toml` проекта — раздел `[nastrojki]` (см. `progress.example.toml`): файлы правил,
файл структуры, папка заданий, описание читателя, команды автопроверок. Плагин сам ничего о проекте
не знает — всё берёт оттуда.

## Установка на своей машине

Нужны Claude Code и Python 3.11+.

```bash
# из клона репозитория, где лежит этот плагин (маркетплейс описан в .claude-plugin/marketplace.json)
claude plugin marketplace add /путь/к/OPD
claude plugin install pisatel@opd                 # для всех ваших проектов (уровень пользователя)
# или только для одного проекта:
claude plugin install pisatel@opd --scope project
```

После установки перезапустите Claude Code или выполните `/reload-plugins`. Для нового проекта
скопируйте `progress.example.toml` в `docs/<проект>/progress.toml` и заполните.

Без Claude Code прогресс можно смотреть и прямо из терминала:
`python3 tools/pisatel/scripts/progress.py docs/metodichka/progress.toml`.
