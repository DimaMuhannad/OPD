# Фирменный стиль ГУАП — извлечено из официального шаблона

Источник: `guap_16-9_2023_1.pptx` («Фирменный стиль презентаций»,
Управление цифрового развития, Отдел цифровой трансформации и сервисов,
2023). Файл передан преподавателем 19.09.2026, разобран через
`python-pptx` (XML-структура шаблона, а не текст на слайдах —
LibreOffice этот файл тоже не открывает, поэтому не отрендерить, только
извлечь параметры). Логотипы — `guap-logo-full.png` (полный, с названием
университета, для титульного слайда) и `guap-logo-compact.png`
(компактный, орбита + «гуап», для всех остальных слайдов) — сохранены
рядом, это подлинные файлы из шаблона, не перерисованы.

## Типографика

- Шрифт по всей презентации — **Arial**, без исключений.
- Основной текст: **18 ± 2 пт** (диапазон 16–20).
- Таблицы (включая заголовки строк/столбцов): **14 ± 2 пт**, обычное
  начертание.
- Заголовок слайда (контентные макеты, `slideMaster2`): **24 пт,
  полужирный, accent1 (#005AAA)**.
- Заголовок титульного слайда (`slideMaster1`): **36 пт, accent1**.
- Основной текст на контентных макетах — dk2 (#002C5F), межстрочный
  110 %.

### Три типа выделения текста (слайд 5, дословно)

1. **Выделение абзаца целиком** — через предустановленный стиль
   («увеличение/уменьшение отступа»): Подзаголовок → Заголовок
   таблицы/диаграммы → Подпись рисунка → Текст → Выделенный абзац →
   Маркеры → Нумерация.
2. **Выделение термина** — курсив + цвет accent1 (#005AAA).
3. **Выделение частного примера** — курсив без цвета.

Подчёркивание не используется нигде в шаблоне.

## Таблицы

Фирменный стиль таблицы из галереи PowerPoint (полосатые строки,
шапка заливкой). Кегль 14±2. Выделение содержимого — accent1.

## Изображения

К изображениям применяется фигурная обрезка: прямоугольник с одним
скруглённым и одним усечённым (срезанным по диагонали) углом — узнаваемый
фирменный приём. В Marp/CSS эквивалент — `clip-path` с одним скруглённым
и одним срезанным углом (см. `.guap-crop` в `theme.css`).

## Что из этого перенесено в `tools/marp/theme.css`

Тема `opd` переписана под эту палитру и геометрию: `--blue: #005AAA`
(accent1), `--ink: #002C5F` (dk2), акцентные цвета из палитры ГУАП вместо
придуманных ранее, Arial, кегли и позиции заголовка/логотипа
приближены к контентному макету шаблона. Полного 1:1 воспроизведения
слайд-мастеров PowerPoint в CSS нет и не требуется — задача была
привести палитру, шрифт, размеры текста и логотип к официальным, а не
скопировать XML-геометрию буквально.
